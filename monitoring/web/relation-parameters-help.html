Parametres des relations

Cette aide decrit les reglages du panneau de droite et de l'assistant. Ils utilisent le meme moteur : modifier un reglage dans l'un revient a modifier la meme relation enregistree.

Principe

Une relation relie une fiche source a une fiche cible. Dans l'exemple courant, un Copieur peut etre lie a des Agents et a des Services. Un Code Copieur est ensuite lie au Copieur et a l'Agent qui l'utilise.

Les relations techniques du mode Attribution sont elles aussi visibles dans l'editeur avance du module ressource. Elles ne sont pas des regles cachees.

Relation, nom et libelle

  • Sens de lecture : indique comment lire le lien, sans changer les fiches deja liees.
  • Verbe : formule le lien dans le schema et les phrases d'aide.
  • Libelle affiche dans la fiche : titre de la section visible pour l'utilisateur.
Exemple : Copieur est utilise par Agent, avec le libelle affiche Agents autorises.

Cardinalite, obligation et activation

ReglageEffetExemple operationnel
Un vers unUne seule fiche de chaque cote.Un badge attribue a un seul Agent et inversement.
Un vers plusieursUne fiche source peut avoir plusieurs cibles ; une cible n'a qu'une source.Un Service possede plusieurs Copieurs, chaque Copieur etant rattache a un seul Service.
Plusieurs vers unChaque fiche source n'a qu'une cible ; une cible peut recevoir plusieurs sources.Plusieurs Codes Copieur sont rattaches au meme Copieur, mais chaque fiche Code est rattachee a un seul Copieur.
Plusieurs vers plusieursLes fiches peuvent etre liees librement des deux cotes.Un Copieur peut etre lie a plusieurs Agents et un Agent a plusieurs Copieurs.

Relation obligatoire impose de renseigner le lien avant de creer la fiche. Relation active rend le lien utilisable dans les fiches ; la desactiver conserve sa configuration mais le retire des choix.

Regles de choix

Limiter les choix aux fiches ayant une relation commune controle la coherence des affectations. Le moteur cherche les liens deja selectionnes et ne propose que les fiches compatibles.

Exemple : un Code est rattache au Copieur CAB. Avec ce filtre, seuls les Agents du Service du CAB sont proposes pour ce Code. Une exception manuelle reste possible depuis la fiche Copieur lorsque la relation manuelle est configuree.

Relations indirectes

Activez cette option seulement si une fiche doit presenter les relations atteignables en passant par le lien courant.

Exemple : depuis un Agent, afficher les Copieurs herites de ses Services lies. Cette option ne cree aucun lien ; elle autorise seulement son affichage.

Mode Attribution : ce reglage ne peut pas etre modifie. Une attribution presente deja les liens directs entre la fiche, le beneficiaire et l'element attribue ; ajouter des relations indirectes rendrait cette synthese ambiguë.

Heritage des Agents

Cette option designe le chemin qui part du module vers les Services. Les Agents deja lies a ces Services sont alors affiches automatiquement sur les fiches du module.

Configuration Copieur : activez l'heritage sur Copieur -> Service. Un Copieur rattache au Service CAB affichera alors les Agents lies au CAB. Les liens Agent-Copieur ajoutes manuellement restent visibles en plus.

Le statut actif dans le titre de l'accordeon confirme que la relation selectionnee est bien celle enregistree dans la configuration d'heritage du module.

Presentation dans la fiche

  • Standard : affiche le lien direct entre les deux fiches.
  • Attribution d'un element lie : regroupe une relation avec une ressource technique intermediaire.
  • Masquee : conserve le lien pour le moteur, sans le dupliquer dans la fiche.
Exemple Attribution : la relation Copieur - Agent utilise la ressource Code Copieur. L'assistant configure les liens Code - Copieur et Code - Agent necessaires a cette presentation.

Valeur unique par element lie

Choisissez le champ de la fiche source qui ne doit pas etre duplique pour une meme fiche cible. Cette regle est locale a la relation, et non globale au module.

Exemple : sur Code Copieur -> Copieur, selectionnez le champ code. Le code 01987 ne pourra apparaitre qu'une fois pour le CAB, mais pourra exister aussi sur un autre Copieur.

Assistant ou editeur avance ?

Utilisez l'assistant pour decrire un cas metier complet, notamment une attribution avec Agent, Service et ressource. Utilisez l'editeur avance pour verifier une relation precise, ajuster un parametre, visualiser le schema ou regler un cas non standard.
